# Open Wobé lexicon leads

## ASJP Wobé wordlist

| Field | Value |
|---|---|
| File | `asjp_wobe_wordlist.json` |
| Source | https://asjp.clld.org/languages/WOBE |
| Language | Wobé / Wè Northern (`wob`, `weno1238`) |
| Entries | **30** concept-word entries (measured from the downloaded `txt` field) |
| Source publication | Hofer and Link (1980), *West African language data sheets*, vol. 2 |
| License | **CC BY 4.0** for the ASJP database |
| Representation | ASJP phonological transcription, **not** the current Wobé practical orthography |
| MT value | Tiny lexicon / normalization and terminology-check seed; **not** parallel-sentence training data |

The English concept labels can be translated to French for a small bilingual
evaluation glossary, but any conversion from ASJP transcription to the project
orthography must be reviewed by a Wobé linguist. Do not silently merge these
forms into the Bible text.
